# UNCLE S3 public development repository

For Lua project work, first read **[developer-kit/AGENTS.md](developer-kit/AGENTS.md)**
and follow its ordered runtime/API/template/check/package/installation workflow.
The versioned downloadable ZIP contains that same AGENTS.md at its extracted root.
The device target is ESP32-S3 Joystick v0.2 international firmware, not P4/C3.
Do not invent interfaces from the product description. Preserve existing user
projects and keep system firmware, private data and unrelated files out of public
content packages. Root product docs have a different scope from the kit MIT license.
