# Starter template

Move a square with the stick; L3 resets. POWER opens the system menu.
Create your own copy with tools/uncle.py new projects/my-game. Edit SPEED/COLOR
in main.lua; keep integer draw coordinates. No external resources or dependencies.
Run check/package from the kit root. This original example is MIT; firmware/fonts
are provided by the device and are not relicensed or included.
