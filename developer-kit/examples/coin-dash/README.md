# Coin Dash

A complete small game: title -> play -> win/time-up -> press to retry.
Stick moves the green square. Collect five gold coins in 18 seconds. POWER opens
the system menu and pauses/exits; system VOL controls loudness. Best coin count
is saved only at results. Current run is discarded on exit.

Copy game.json/main.lua/assets.bvp/README.md/LICENSE.txt together; use SDK package
command. The tiny coin sprite and collect sound are original procedural assets
under MIT. Build sources are in resources/coin-dash-source, with a rebuild tool.
No downloaded font/music/image is used. SPEED/DURATION/points in main.lua are
the intended editing points. Not device-playtested in this public-kit round.
