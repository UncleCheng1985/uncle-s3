# Pocket Counter

An interactive application launched through Games, using the same Lua lifecycle.
Right/Up increments, Left/Down decrements (0..999999), L3 resets. POWER pauses
and exits. Holds do not auto-repeat; use fresh stick edges. It saves on changes
via the existing deferred per-project store; not a cloud/shared/system counter.
No external assets. MIT applies to this code, not the firmware or built-in fonts.
Host behavior tests pass; this public-kit round has no device run.
